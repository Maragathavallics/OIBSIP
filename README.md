## 📌 About This Repository

Welcome to my **Oasis Infobyte Internship Projects Repository**!

This repository showcases the five projects I completed during my Data Science and Machine Learning internship at Oasis Infobyte.

The internship provided an opportunity to apply theoretical knowledge to practical problems through Python programming, exploratory data analysis, data visualization, and machine learning model development.

Each project demonstrates different aspects of the data science workflow, from data preprocessing and visualization to predictive modeling and model evaluation.

## 🎯 Internship Objectives

- Gain hands-on experience in Python programming.
- Understand real-world datasets and data preprocessing.
- Perform Exploratory Data Analysis (EDA).
- Develop and evaluate Machine Learning models.
- Apply classification and regression techniques.
- Improve analytical and problem-solving skills.

## 📂 Projects Overview

### 01. Iris Flower Classification
**Domain:** Machine Learning – Classification

**Objective:** Develop a classification model to predict Iris flower species based on their physical measurements.

**Key Activities:**
- Dataset exploration and preprocessing.
- Feature analysis and visualization.
- Classification model development.
- Model performance evaluation.

### 02. Unemployment Analysis with Python
**Domain:** Data Science – Exploratory Data Analysis

**Objective:** Analyze unemployment data to understand employment trends and patterns.

**Key Activities:**
- Data cleaning and preprocessing.
- Exploratory Data Analysis.
- Unemployment trend analysis.
- Data visualization using Python libraries.

### 03. Car Price Prediction with Machine Learning
**Domain:** Machine Learning – Regression

**Objective:** Build predictive models to estimate car prices using relevant vehicle features.

**Key Activities:**
- Data preprocessing and feature engineering.
- Exploratory Data Analysis.
- Regression model development.
- Model comparison and evaluation.

### 04. Email Spam Detection with Machine Learning
**Domain:** Machine Learning – Classification / Natural Language Processing

**Objective:** Develop a classification system to distinguish spam messages from legitimate messages.

**Key Activities:**
- Text data preprocessing.
- Feature extraction.
- Classification model development.
- Model evaluation using classification metrics.

### 05. Sales Prediction Using Python
**Domain:** Data Science – Predictive Analytics

**Objective:** Analyze historical sales data and develop a model to predict sales based on relevant features.

**Key Activities:**
- Data exploration and preprocessing.
- Sales trend analysis.
- Predictive model development.
- Model performance evaluation.
